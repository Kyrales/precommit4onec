# Утилита для автоматической обработки исходных файлов конфигурации, внешних отчетов и обработок для платформы 1С:Предприятие при помещении в репозиторий git

# Форк базового решения: https://github.com/bia-technologies/precommit4onec

## Отличия от базового решения

Добавлено/изменено по функционалу:
1. Исправлено: Не работает параметр rules в команде exec-rules в случае, если включено использование локальных сценариев https://github.com/bia-technologies/precommit4onec/pull/55 . Есть тесты
2. Исправлено: При коммите не должны попадать в изменения файлы, которые не входят в текущий каталог https://github.com/bia-technologies/precommit4onec/pull/46 . Есть тесты
3. Возможность отключения локальных сценариев через настройку Отключенные https://github.com/bia-technologies/precommit4onec/pull/50

Новые правила:
1. Анализ наличия физических файлов, которые указываются в ПВХ. Обновлено правило "СинхронизацияОбъектовМетаданныхИФайлов". https://github.com/bia-technologies/precommit4onec/pull/48 . Есть тесты
2. Проверка корректности XML-файлов. Новое правило "ПроверкаКорректностиXML" . https://github.com/bia-technologies/precommit4onec/pull/52
3. Проверка дублирования уникальных идентификаторов в метаданных конфигурации. Новое правило "ПроверкаДублейУникальныхИдентификаторов" . https://github.com/bia-technologies/precommit4onec/pull/53
4. Проверка на наличие артефактов после разрешения конфликтов (актуально при использовании сравнения через Meld) . Новое правило "ПроверкаНаличияАртефактовGit" . https://github.com/bia-technologies/precommit4onec/pull/54

## Установка

1. Скачать из релизов свежую версию `precommit4onec-*.ospx`
2. Установить в библиотеку OneScript командой:
```BSL
opm install -f precommit4onec-НОМЕР_ВЕРСИИ.ospx
```
